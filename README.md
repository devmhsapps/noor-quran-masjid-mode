# نور القرآن — وضع الجامع

نسخة Android تجريبية مكتوبة بـ Flutter، مخصصة لاختبار وضع عدم الإزعاج المؤقت واستعادته تلقائياً.

## الميزات

- شاشة بداية إسلامية مع «بسم الله الرحمن الرحيم».
- وقت مخصص بالساعات والدقائق والثواني حتى 24 ساعة.
- طلب إذن الإشعارات عند أول دخول، وطلب الموقع فقط عند اختيار المستخدم له.
- فتح إعداد عدم الإزعاج الرسمية عند الحاجة.
- خدمة Android أمامية تعيد وضع الهاتف السابق عند انتهاء الوقت.
- تنبيه صوتي عربي عند انتهاء الجلسة: «تم إيقاف الوضع الصامت. تقبل الله صلاتكم.»

## البناء والتنزيل

يُبنى APK عبر GitHub Actions. بعد تشغيل مسار **Build Android APK**، يظهر APK في قسم Artifacts. وعند إنشاء وسم إصدار مثل `v1.0.0`، يُنشر APK في GitHub Releases برابط تنزيل عام.

## تجربة Android

1. ثبّت APK على هاتف Android 6 أو أحدث.
2. وافق على إشعارات التطبيق عند ظهور الطلب.
3. اضغط زر منح صلاحية وضع الجامع ثم اسمح بالوصول من إعدادات Android.
4. اختر مدة قصيرة بالثواني واختبر الاستعادة والصوت.
