# مزودو المحتوى ولوحة الإدارة والتحديثات

## مصادر يمكن إدارتها من لوحة الإدارة

| المجال | مزود مرشح | ما نستخدمه | القيد الأساسي |
|---|---|---|---|
| ترجمات معاني القرآن | QuranEnc API | قائمة الترجمات، ترجمة السورة أو الآية، ونسخ المحتوى للمزامنة المحلية بعد مراجعة سياسة المصدر. | التحقق من شروط كل ترجمة ومصدرها قبل النشر أو التخزين المحلي. |
| بيانات قرآن من Quran Foundation | Quran Foundation APIs | محتوى أو بحث أو بيانات عبر واجهة رسمية بعد إنشاء حساب المطور. | لا يجوز بيع أو إعادة ترخيص أو إعادة توزيع محتوى QF أو بيانات API الخام دون ترخيص تجاري مكتوب. |
| مواقيت الصلاة | AlAdhan API | مواقيت حسب الإحداثيات أو المدينة وطريقة الحساب، مع حفظ نتيجة اليوم محلياً. | مراجعة الشروط والاعتمادات قبل التشغيل والإبقاء على خيار الحساب المحلي والمدينة اليدوية. |
| صور وملفات التطبيق | روابط تضعها الإدارة في تخزين مرخّص | رابط ثابت، حجم، نسخة، نص بديل، ورخصة/مصدر. | لا يحمل Firestore الملف نفسه؛ الجهاز ينزّل الرابط ويحفظه محلياً عند الحاجة. |

## لوحة الإدارة

تكون لوحة الإدارة مركزاً واحداً للمحتوى، ولا تمنح للنشر إلا للمدير أو مراجع محدد. تضم أقساماً للمزودين، المواد، الوسائط، الأذكار، أصوات الأذان، الإشعارات، والإصدارات. كل مادة تسجل مصدرها ورخصتها وصاحب مراجعتها وحالة النشر، ولا تظهر للمستخدم قبل الاعتماد.

## التحديثات

تحتاج لوحة الإدارة إلى سجل إصدارات يتضمن رقم النسخة الأدنى والنسخة الأحدث ورابط الإصدار وملاحظات التحديث ومستوى الإلزام. عند فتح التطبيق أو عند الضغط على «تحقق من التحديث» من القائمة الجانبية، يفحص التطبيق هذا السجل ويعرض نافذة مناسبة.

التوزيع عبر Google Play يسمح بمسار تحديث رسمي داخل التطبيق: تنزيل مرن في الخلفية، أو تحديث فوري يعيد تشغيل التطبيق عند قبول المستخدم. أما إصدار APK عبر رابط خارجي، فيستطيع التطبيق تنزيله بعد موافقة المستخدم وفتح مثبّت Android، لكن لا يثبت نفسه بصمت أو من دون تأكيد المستخدم. كما أن صلاحية REQUEST_INSTALL_PACKAGES مقيّدة في Google Play للتطبيقات التي يكون تثبيت الحزم غرضاً أساسياً لها، ولذلك لا نضيفها لتطبيق قرآن منشور في المتجر.
