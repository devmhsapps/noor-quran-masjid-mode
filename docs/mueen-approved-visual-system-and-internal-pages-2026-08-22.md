# هوية مَعين المعتمدة والصفحات الداخلية

## الهوية المعتمدة

اعتمد المستخدم اتجاه مَعين البصري في المعاينات الأخيرة: خلفية عاجية دافئة، أخضر غامق، ذهبي هادئ، زخرفة هندسية خفيفة، بطاقات واسعة، وأيقونات خطية داخل دوائر ناعمة. يبقى هذا النظام مستقلاً عن التطبيقات المرجعية من حيث الخلفيات والساعة والرموز وشكل البطاقات.

| العنصر | التطبيق في مَعين |
|---|---|
| الخلفية | عاجي دافئ `#F8F5EE` مع هندسة إسلامية شفافة جداً. |
| اللون الرئيسي | أخضر غابة `#0B3D2E` للأزرار والحالات النشطة. |
| التمييز | ذهبي `#C58A28` للمؤشرات والتقدم واليوم المحدد. |
| التنقل | رموز دائرية، حالة نشطة خضراء، وخمسة أقسام ثابتة. |
| الوضع الليلي | أخضر ليلي `#0B1713` مع نص فاتح وذهبي مطفأ. |

## مجموعة الصفحات الداخلية التالية

| الصفحة | الغرض | التفاعل الأساسي في الويب |
|---|---|---|
| وضع الجامع | تفعيل الصامت المؤقت واستعادة الصوت بعد المدة | اختيار المدة، عرض الحالة، ومراجعة الصلاحيات. |
| ورد وختمات | متابعة خطة القراءة والإنجاز المحلي | اختيار خطة، زيادة التقدم، وفتح المحفوظات. |
| الدعم الفني | إرسال طلب ومشاهدة حالة المحادثة | كتابة رسالة، إرفاق صورة تجريبية، وتبديل حالة الطلب. |
| المدينة والموقع | تحديد المدينة وطريقة الحساب والخصوصية | بحث، اختيار مدينة، وتبديل الموقع الاختياري. |
| محرر التذكير | إنشاء تذكير مرتبط بوقت أو صلاة | تعبئة الخطوات وحفظ معاينة محلية. |
| مكتبة الأصوات | تنزيل واختيار صوت تنبيه وحذف المحفوظ | اختيار صوت، مشاهدة الحجم والتقدم، وحذف النسخة المحلية. |

## المصحف

يبقى المصحف مساراً مستقلاً كامل الشاشة يشمل: فهرس السور والأجزاء، البحث، الانتقال إلى آية، أدوات الآية، آخر موضع، العلامات والملاحظات، ورد وخطة ختمة، وضع تركيز، ونظام ليلي مريح. تُبنى ميزات التفسير أو الصوت لاحقاً فقط بعد اختيار مصدر مرخّص وموثوق.
