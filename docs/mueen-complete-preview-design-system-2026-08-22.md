# نظام الهوية لمجموعة معاينات مَعين

## الهدف

تعرض المجموعة جميع وظائف مَعين بترتيب مألوف لتطبيقات المواقيت، لكن بواجهة أصلية لا تنسخ خلفية أو ساعة أو رموز أو تخطيط المرجع. القياس المعتمد هو هاتف عمودي بنسبة 9:16، من اليمين إلى اليسار، وتكون عناصر التحكم ضمن مدى الإبهام في أسفل الشاشة.

## قواعد مَعين البصرية

| العنصر | القرار |
|---|---|
| لون النهار | عاجي دافئ `#F8F5EE`، أخضر غابة `#0B3D2E`، ذهبي هادئ `#C58A28`. |
| لون الليل | أخضر ليلي عميق `#0B1713`، أخضر نعناع هادئ `#76C79F`، ذهبي مطفأ. |
| الخلفية | نقش هندسي إسلامي خفيف جداً أو تدرج ضبابي، لا صورة مسجد أو خلفية مرجعية. |
| مؤشر الصلاة | قرص هلالي ذهبي غير ساعة تقليدية، مع حلقة تقدم ووقت الصلاة التالية. |
| البطاقات | زوايا 20–24 بكسل، ظلال ناعمة، حدود دقيقة، ومساحات واسعة. |
| الأيقونات | رموز خطية بسيطة داخل دوائر خضراء أو ذهبية، مختلفة عن أيقونات المرجع. |
| التنقل | خمسة رموز سفلية دائرية: الرئيسية، صلاتي، المصحف، الأذكار، المزيد. |

## الشاشات التي ستظهر في المعاينات

1. الرئيسية اليومية: التاريخ والموقع والصلاة التالية ومواقيت اليوم وملخص الورد.
2. صلاتي: الصلاة التالية، قائمة المواقيت، المدينة وطريقة الحساب.
3. المصحف: فهرس وسورة وقارئ كامل الشاشة.
4. الأذكار وذكّرني: مصادر المحتوى والتذكيرات الشخصية.
5. القبلة: بوصلة ومعايرة ودرجة ومسافة، وخريطة اختيارية.
6. ليلتي وصيامي: ملخص اليوم والجدول الشهري.
7. التقويم: الشهر الهجري/الميلادي ومواقيت اليوم المحدد.
8. إعدادات الأذان: صوت محفوظ، إقامة، اهتزاز، وصامت مع الصلاة ضمن حدود النظام.

## تحقق المعاينات الأولى

أظهرت معاينة الرئيسية قرص الصلاة الهلالي الخاص بمَعين، التسلسل اليومي، وبطاقات وضع الجامع ومتابعة القراءة مع تنقل سفلي دائري. وأظهرت معاينة المصحف عنوان السورة وبياناتها ثم آيات كبيرة ذات رقم مستقل، مع فهرس جانبي داكن واضح. تُعد هذه العناصر مرجع الاتساق لبقية لقطات المجموعة، ولا تمثل نسخاً لتصاميم مرجعية.
