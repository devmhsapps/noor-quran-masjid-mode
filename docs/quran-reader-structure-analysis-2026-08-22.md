# تنظيم قارئ مَعين بعد تحليل الفيديو

## البنية المعتمدة

يعرض رأس القارئ اسم السورة ومؤشر الموضع والحفظ بوضوح. تحت الرأس تبدأ مساحة قراءة هادئة، وفيها كل آية بصفتها عنصراً مستقلاً: رقم صغير منفصل، ثم النص العثماني الواسع. لا يدمج الرقم داخل النص ولا يتحول كل سطر إلى بطاقة ثقيلة؛ النص هو العنصر البصري الأهم.

| المنطقة | قرار مَعين |
|---|---|
| الرأس | اسم السورة، عدد الآيات، موضع القراءة، وفهرس جانبي. |
| الآية | رقم دائري صغير في هامش الآية ثم النص بعرض مريح وتباعد هادئ. |
| الضغط المطول | علامة ملونة، مفضلة، ملاحظة، ومكان لاحق للتفسير من مصدر مرخّص. |
| الأسفل | تصغير، تكبير، فهرس، وضع تركيز، ثم أسهم انتقال لاحقاً. |
| التمرير | عمودي متصل مع حفظ آخر آية نقر عليها المستخدم. |

## تمييز مَعين

لا يعيد مَعين استخدام هوية أو رموز أو ألوان الفيديو المرجعي. يستخدم خط Amiri Quran المدمج، وخلفية مَعين العاجية أو الليلية، والذهب للإشارة إلى موضع أو علامة فقط.
