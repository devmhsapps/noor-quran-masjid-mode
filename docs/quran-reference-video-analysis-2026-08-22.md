# تحليل الفيديو المرجعي للمصحف

## الوظائف الظاهرة

أظهر الفيديو تجربة مصحف تتمحور حول فهرس السور والأجزاء، وقارئ النص العثماني، وأدوات منظمة للمتابعة. من الوظائف المناسبة لتكييفها في مَعين: البحث، بيانات السورة، الفواصل الملونة، المفضلة، الملاحظات، خطة الختمة، إعدادات القراءة، وتنبيه الورد اليومي.

| الوظيفة المرجعية | قرار مَعين | الحالة |
|---|---|---|
| فهرس السور والأجزاء مع رقم الصفحة والآيات ومكية/مدنية | فهرس مَعين سريع في اللوحة الجانبية، مع بحث وتفاصيل مختصرة | مخطط ضمن قارئ المصحف الكامل. |
| لمس الآية لفتح أدوات | قائمة سياقية أصلية للعلامة والملاحظة والمشاركة والانتقال | مخطط. |
| تفسير مختصر وصوت تفسير | يضاف فقط بعد اعتماد مصدر نصي وصوتي مرخّص وموثوق، ولا يستخدم محتوى مجهول المصدر | مؤجل. |
| آية اليوم | بطاقة محلية قابلة للمشاركة، مع تاريخ ومصدر النص | مخطط. |
| الختمة والفواصل والمفضلة والملاحظات | موجودة محلياً كبنية أولية وتحتاج واجهة موحدة في القارئ الجديد | قيد التكييف البصري. |
| المظهر الليلي وتذكير القراءة | الوضعان موجودان؛ يضاف تذكير ورد يومي في إعدادات التنبيه | مخطط. |
| نسخ احتياطي | تصدير واستيراد محلي اختياري قبل ربط أي خدمة سحابية | لاحقاً. |

## التدفق المعتمد لمَعين

يبدأ المستخدم من **المصحف** ثم يفتح لوحة الفهرس للبحث أو اختيار سورة أو جزء. عند القراءة يستطيع الضغط على آية لإضافة علامة أو ملاحظة أو فتح شرح عندما يتوفر مصدر مرخّص. تعود أدوات الختمة والمحفوظات والملاحظات من خلال لوحة المصحف نفسها، مع بقاء «متابعة القراءة» في الصفحة الرئيسية.
